Fixed: a bootstrap now creates the off-plan record. The starter answers set `paths.offPlan` (`docs/development-plan/off-plan`) for a new project, and the scaffold writes the folder's `README.md` (the format of a record) from the new template `off-plan-readme.md`, so `harness check off-plan` runs from the start. A project that is already adopted keeps its profile file as it is; to turn the record on it adds `paths.offPlan` to its profile file, a folder with a `README.md` in the same format, and runs `harness sync` (as the note of the off-plan record says).
