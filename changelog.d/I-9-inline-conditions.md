Fixed: a condition inside a line of a procedure (`… {{#if role}} … {{/if}} …`) is rendered instead of copied into the generated skills. The template engine knew the blocks `if`, `unless` and `each` only with each tag on a line of its own, so the skills `change-plan`, `end-session`, `triage-reports` and `run-flow` shipped the raw `{{#if …}}` and `{{/if}}`. A condition closed on the same line now keeps or leaves out the text between its tags, a role inside it is optional (a profile without it no longer stops the sync), and any other block tag inside a line is an error rather than text. A project takes the fix with the sync, which rewrites its skills.
