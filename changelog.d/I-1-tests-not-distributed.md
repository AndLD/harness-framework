Fixed: `harness sync` no longer copies the framework's tests (`*.test.mjs`) into a project. They prove the framework against its own repository (its profile file, every preset, its documents), so in a pinned project 20 of 428 failed for what the project does not have, and nothing in a project runs them. `framework.json` lists the file name endings a sync leaves out in `excluded`; the next sync removes the test files from `harness/`.
