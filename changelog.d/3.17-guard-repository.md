Fixed: the Git guard of the agent runtime (`guard-shell`) judges each Git command by the branch of the repository the command acts on, not by the branch of the project directory. It follows a `cd` before the command (a `cd` inside parentheses ends with them), `-C`, `--git-dir` and the variables `GIT_DIR`, and a repository it cannot resolve (an unknown directory, a variable, `--work-tree` alone) is judged as a protected branch. A commit in another clone's task branch is no longer refused while the project is on its integration branch, and a commit or push in another clone's integration branch is no longer allowed while the project is on a task branch.
