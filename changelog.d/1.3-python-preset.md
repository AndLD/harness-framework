Added: the Python stack preset (`adapters/stack/python/`; task 1.3), written by following the new-adapter procedure: uv workspaces, pytest with coverage.py (branch coverage; the raw report is merged and turned into the neutral summary by `coverage.mjs`), ruff for lint (E, F, I, B, UP, ANN, T20) and format, mypy in strict mode; the local gate plan (`gate.mjs`), the CI jobs, and a scaffold with a root `pyproject.toml`, `.python-version` and `.nvmrc`. A project selects it with `adapters.stacks`, alone or next to `node-ts`. The project creates `uv.lock` once with `uv lock` and commits it: CI installs with `uv sync --locked`.
