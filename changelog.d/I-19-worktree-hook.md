Changed: the Git hooks `pre-push` and `pre-commit` run the tools of the tree that runs them: in a linked worktree, whose `core.hooksPath` names the main checkout, they use the worktree's own `harness.mjs` (found at the same path below its top folder) instead of the main checkout's, so the worktree's generated files are checked against its own `core/`. A project has nothing to do; a hook folder outside the project tree, or a worktree without the file, behaves as before.
