Fixed: the quiet test commands of the node-ts preset (I-31). `testQuiet` and `testCoverageQuiet` are for a single package; a project whose root script is `npm run test --workspaces` writes `testQuiet` as `npm run --silent test --workspaces --if-present -- --reporters=summary --silent` (and `testCoverageQuiet` the same way), because there npm takes the flags after `--` and Jest never sees them (the take of 0.5.0-dev.1 measured −75% output with this form, none with the default). The preset now also defaults `typecheckQuiet` (`npm run --silent typecheck`) and `formatQuiet` (`npm run --silent format -- --log-level warn`).
