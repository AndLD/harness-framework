Added: `harness plan-write on|off|state [--folders <a,b>] [--scope project|local|user]` lets an agent write the plan's files (the plan, its phases, flows, issues and backlog, and so the logs) without a permission prompt of the agent runtime. It is a new optional logic role of the agent-runtime contract, `plan-write` (a minor addition to contract 2: an adapter without it still conforms); the Claude Code preset fills it with `Edit(<folder>/**)` rules in `permissions.allow` of the project's tracked `.claude/settings.json` (the ignored local file or the user-wide one only with `--scope`), and refuses the settings file, the hooks and the Git directory. A new project's bootstrap (`harness init`, `harness bootstrap`) turns it on, says so in its output, and takes `--no-plan-write` to leave it off; the user-wide setting is never turned on by the bootstrap. A project that took an earlier version runs `harness plan-write on` once, if it wants the permission.
