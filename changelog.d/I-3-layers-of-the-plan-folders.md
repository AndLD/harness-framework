Fixed: the migration script of `0.2.0` adds the phase folders and the issue queue to the layer map of a project that has one of its own. Such a project listed `<phases>/phase-*.md` in a layer and not the folders, so `harness check layers` failed on every file of a phase folder and of the queue, and `check paths` read the finished tasks the one-file phases were exempt from as state documents. The script adds `<phases>/phase-*/**` and `<issues>/**` as lines of the layer that claims the one-file phases, where no layer claims the folders already, and says what it added (or what to add by hand, when the file cannot be edited safely). A project that did this by hand is left as it is.
