Added: a security review method in `core/reviews/security/` (dimensions S1 to S6, the probe format, the rules of engagement for active tests, where results go and the loop of a review), with a report template, a bindings template, and the procedure `security-review`, which runs where the profile sets the new optional role `documents.securityReviews`. To use it, set `documents.securityReviews` and `documents.securityBindings` (the starter values are in `profile/starter.json`), copy the bindings template of the scaffold to the second path, and run the sync.
Changed: the code review's C7 and K11 link to the security review instead of repeating it; a project whose code-review bindings give a command for K11 updates it.
