Changed: the defects and improvements found in use are no longer a phase that never ends. They are an issue queue, `paths.issues`: a file per issue (`I-<n>.md`, with `Area:`, `Reported:` and its log beside it), an index of the open ones, and `archived/` where `harness plan summary` moves the finished ones. Branches are `bugfix/I-<n>-<slug>`; "Work the issue queue" and "Fix I-<n>" approve their pull requests. The migration script of this version turns a project's open-ended phase into a normal phase that keeps every id, makes only its defects that have not started into issues (`I-1, formerly 12.5`), and replaces `plan.openEndedPhase` and `plan.openEndedPhaseNumber` of the profile file with `paths.issues`. `harness check plan` fails when an order names an id that exists nowhere.
