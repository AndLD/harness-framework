Changed: the procedures that the method requires of every agent unasked can be loaded by the agent: `start-task`, `end-session`, `finish-phase` and `triage-reports` are `invocation: auto`, so the Claude Code preset (and Cursor) no longer writes `disable-model-invocation: true` into their skills. The procedures a person starts or that act outside the repository stay `explicit` (`release`, `code-review`, `harness-review`, `new-adapter`, `update-framework`, `report-upstream`). The format says it: `explicit` is only for a procedure that an agent must not start on its own judgment (design §8.1). A project takes the change with the next `sync`, which rewrites the four skills; nothing else to do. A procedure of the project's own folder (`paths.procedures`) follows the same rule.
