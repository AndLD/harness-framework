Added: a setting `commands` of a flow (the flow template and the plan method): `any`, the default, leaves the workers to write commands as they like, heredocs included, as before; `plain` adds a section to the prompt of each step that asks for files written by the runtime's edit and write tools (no heredoc or redirection into a file), no nested commands or subshells, and independent commands as parallel calls of one message, so that a strict permission mode of the agent runtime can check each command before it runs and asks the owner less. `harness flow check` refuses another value. A project has nothing to do; a flow whose workers run in a strict mode may set `"commands": "plain"`.
