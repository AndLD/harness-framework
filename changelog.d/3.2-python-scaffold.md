Fixed: a new Python project is green in its static checks, and says what it still needs. The python stack scaffolds a `pyproject.toml`, a typed first module and a test in each package (at the root when the project has none), so that `uv lock` finds every workspace member and `mypy .` finds a source file. The lock file cannot be written by the scaffold, so the new manifest field `firstSteps` of an adapter lists what a project does once by hand (the python stack: run `uv lock` and commit `uv.lock`, without which CI, which installs with `uv sync --locked`, is red): the bootstrap prints those steps and the scaffolded stack file lists them.
