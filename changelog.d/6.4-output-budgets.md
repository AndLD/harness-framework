Added: output budgets for agents and a short, capped schema for the step report of a flow's worker. The method has a new section 8 (read with a filter, the quiet variant of a command, short pull request bodies, commit messages, log entries and closing messages, with long text in a file of the plan) and its definition of done a matching line; the step prompts (`core/plan/flow-step-prompts.md`) get a `budget` section for every step and a `report` section with the schema (Status, Merged, Decisions, Deviations, Next step, then Recommendations) and a hard cap of 30 lines and 2,400 characters, the rest going to the task's log; `harness flow report-check <file>` checks a saved report against both; the procedures `run-flow`, `start-task`, `open-pull-request` and `end-session` cite the budgets. A project takes it with `harness sync` (the procedures' packaged skills are regenerated); a flow file of a project that has its own `custom` step still gets the budget and report sections.
