Added: the procedure `change-plan` (invocation `auto`, so an agent loads it as a skill on its own): adding a task, adding a phase, recording a defect or an improvement found in use as an issue, and splitting a phase. It tells the agent to read the plan method, the rules of a phase file and the template first, never to copy an old phase, task or issue, and to leave every generated block to `harness plan summary`. Its row is in the procedures block of the entry file and its skill is written by the next `sync`.
