Added: the optional runtime role `managed-blocks` (`managedBlocks(profile) → [{ path, block, content }]`) for blocks of a file of the project that the sync keeps up to date between `# harness:begin <block>` and `# harness:end <block>` lines, as an ignore file needs (an HTML comment would be a pattern). The sync adds the block at the end of the file when the file lacks it and makes the file when it is missing, so the project's own lines stay; `check generated` and the lock hold the block like any other. The packaging of a procedure may now return no path for a profile (`skillPath(procedure, profile)`). A project that wrote an adapter of its own needs no change.
