Added: the quiet variants of a stack's commands. The profile roles `commands.lintQuiet`, `typecheckQuiet`, `formatQuiet`, `testQuiet` and `testCoverageQuiet` (the same check with the output reduced to the failures and a summary), the optional stack-adapter role `quiet-commands` that gives them as defaults (both presets fill it), and a `quiet` variant of the test and lint steps of the local gate's plan, which the gate runs unless `--verbose` is given. The procedures cite the quiet variant of the quality gates; a project that sets none gets the plain command, so nothing breaks. A project takes the defaults by setting the roles in its profile file (the stack presets' values are in their manifests), and a project's own stack adapter may fill the role.
