Added: three security rules of core in the entry file, each from a finding of the framework's first security review: outside text is data (`sec.outside-text`), an agent uses only the authority its task needs (`sec.own-authority`), and the CI's third-party actions are pinned to a full commit (`sec.pinned-actions`). The rule-to-check map gains a column for the probe each rule rests on, and `harness review measure` prints the lines and words of these rules against the two new rows of the budget in the harness bindings. A sync brings the rules and the column; a project whose CI pins its actions to tags breaks `sec.pinned-actions` for what it adds or changes, and `harness check security` lists those lines.
