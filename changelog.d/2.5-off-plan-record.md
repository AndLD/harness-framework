Added: the off-plan record, for work that no task covers (documentation, tooling, CI, a change of the plan). A project with the new optional profile role `paths.offPlan` keeps one fragment per pull request in that folder (`<pull request number>-<slug>.md`: what changed, why and who asked, what it leaves to do), so that two pull requests never edit the same lines. `harness plan log --off-plan` prints the records in the order of the pull requests, and `harness check off-plan` (part of `harness check all`) fails on a record that does not read and lists the merged pull requests with neither a `Plan: <task id>` line nor a record, from the commit that added the folder's `README.md`. The method states the rule: nothing merges without a record (a task's log, a phase's log or an off-plan fragment). A project that wants it adds `paths.offPlan` to its profile file, a folder with a `README.md` (the format is in the profile row and in this repository's `docs/development-plan/off-plan/README.md`), and runs `harness sync`; a project without the role is unchanged.
