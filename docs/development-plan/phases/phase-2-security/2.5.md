# 2.5 — Off-plan record (from the second source)

**Status:** ⬜ · **Agent:** C2 · **Size:** 3 SP

**Off-plan record (from the second source)**: Work that no task covers (documentation, tooling, CI, plan changes merged without a `Plan: <task id>` line) gets a record in its own pull request: what changed, why and who asked, and what it leaves to do. Unlike the second source's single append-only file, each record is a **fragment** (one file per pull request, like the changelog fragments), so parallel pull requests never edit the same lines; `harness plan log --off-plan` prints them in order. The core method states the rule ("nothing merges without a record: a task's log, a phase's log or an off-plan fragment"), and a check lists merged pull requests without a `Plan:` line and without a fragment. Tests with a fixture history.
