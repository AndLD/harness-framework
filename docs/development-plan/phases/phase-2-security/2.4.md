# 2.4 — First security review of the framework itself

**Status:** ⬜ · **Agent:** C3 · **Size:** 3 SP · **Needs:** 2.8, 2.9

**First security review of the framework itself**: A report in the framework repository by the method of 2.1 and the catalogue of 2.8 and 2.9 (the probes of S1 to S4 that apply), on S1 to S4 (the framework has no product runtime, so S5 and S6 are "not applicable" with the reason), its findings triaged. The report also has a section on the method itself: a probe that did not apply, one that was unclear, one that is missing, a step of the procedure that did not work; each is an issue or an edit of the catalogue, and the findings are sorted as the loop of 2.1 says, which feeds task 2.10.
