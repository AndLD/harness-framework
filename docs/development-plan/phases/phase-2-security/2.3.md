# 2.3 — Automated review measurements

**Status:** ✅ · **Agent:** C2 · **Size:** 3 SP

**Automated review measurements**: `harness review measure` prints the measurements that four harness reviews ran by hand: words and normative words in the always-loaded set, rule-map statuses, the reference direction between layers, unreachable files and the highest fan-out, against the budgets of the bindings. The harness review method cites the command instead of the shell lines. Verified against the numbers of the last report on the same commit.
