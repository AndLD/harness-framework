# 3.9 — The claim rule does not say who owns a claim after its session ends

**Status:** ✅ · **Agent:** C2 · **Size:** 3 SP · **Log:** [3.9.log.md](./3.9.log.md)

**The claim rule does not say who owns a claim after its session ends**: method §6 says a task with an open pull request "belongs to the session that opened it, and nobody else starts it", and §7 that an agent "never starts a task that has an open pull request"; but §6 also tells a session that continues a phase to go on from the latest "next step", which is often a task that a paused session claimed. Nothing tells a session its own earlier claim from a live claim of another agent. In the closing review of the extraction, three probes read the same state (a draft claim open) two ways: one took the task over, two left it alone (finding H-20261103-02 of AndLD/bot-rts). One rule in method §6 and §7: a claim belongs to its session while that session works; a session that resumes a phase continues a claimed task when the task's log or the phase log records a pause or a "next step" that names it, or when the owner says so; otherwise it asks. The resume step of the procedure `start-task` says the same. **Also in `start-task`:** it chooses "the next ⬜ task of the phase … in the plan's order", which reads as the order of the table; a session told "Start Phase 3" here would start with 3.1, though the order of development starts with 3.6. Step 2 chooses the next task by the phase's execution order, and by the plan index's order of development when the phase points there; the table's order only when neither exists. When no phase is in progress, the session-start hook prints the next task by that rule (today it prints only that no phase is in progress). Verified by the CORE scan and the generated skills, by a hook test on a plan whose execution order differs from its table, by a probe on that plan told "Start Phase N" that picks the right task, and by two probes on a scratch project with an open claim: with a log entry that names it as the next step the agent continues it; without one it asks.
