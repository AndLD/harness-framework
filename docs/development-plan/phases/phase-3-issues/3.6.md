# 3.6 — The framework's own CORE scan knows only the tools of its adapters

**Status:** ✅ · **Agent:** C1 · **Size:** 1 SP · **Log:** [3.6.log.md](./3.6.log.md)

**The framework's own CORE scan knows only the tools of its adapters**: `terms.stack` of the framework's profile file and the adapters' `terms` name Node, Python, Claude Code, Cursor and GitHub words. Broaden `terms.stack` with these classes of tool names. Neutral words stay out (for example "database" or "container").
