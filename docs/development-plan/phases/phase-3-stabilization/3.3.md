# 3.3 — The command line and the runtime hooks do nothing, with exit code 0, when started through a symbolic link

**Status:** ✅ · **Agent:** C1 · **Size:** 2 SP · **Log:** [3.3.log.md](./3.3.log.md)

**The command line and the runtime hooks do nothing, with exit code 0, when started through a symbolic link**: `process.argv[1]` is the link and `import.meta.filename` the real path, so `resolve(process.argv[1]) === resolve(import.meta.filename)` is false in `tools/harness.mjs` and in each runtime hook. A project under a linked path would have its hooks switched off without a message. Compare real paths (`realpathSync`) in all of them. Verified by a test that runs the command line and a hook through a link. Found by the conformance suite in task 17.14 of the project this framework was extracted from.
