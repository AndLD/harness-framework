# 4.5 — Measure and budget the procedures block; default probes

**Status:** ✅ · **Agent:** C1 · **Size:** 2 SP

**Measure and budget the procedures block; default probes**: The harness-review method counts the rows of the `procedures` block in the always-loaded measurement (its M6/M20) and the bindings of a project set a budget for them; the method requires the cold-start probes of a project to include the extension of a document (add a phase, put a defect into the open-ended phase), and the scaffold's bindings stub ships them as starting probes beside the routine ones. The method also says how a probe runs: a probe of another repository (a scratch project, a newly bootstrapped one) runs as a separate session started in that repository, so it loads that repository's entry file and session-start hook, not those of the reviewing repository; a subagent of the reviewing session inherits its entry file and gets no hook (seen in the closing review of AndLD/bot-rts, 2026-11-03). Verified by the scaffold test and the CORE scan (0).
