# 4.3 — Procedure `change-plan`

**Status:** ✅ · **Agent:** C1 · **Size:** 2 SP

**Procedure `change-plan`**: Add a task (the next free id, size, `Agent` marker, the title size, the summary), add a phase (from the phase template: file, work log, index row and contents line from the plan-summary command), split or merge (`phases.md` section 8). Invocation `auto`, with a trigger line that names both situations, and its row in the `procedures` block. It tells the agent to read the template and the rules first and never to copy an old phase. Verified by running the extension probes of the harness-review method (add a phase, put a defect into the open-ended phase) by hand on a scratch project, and recording what each read first.
