### 2026-11-04 — the procedures every agent starts unasked are `auto`
- **Branch:** `feature/4.4a-auto-procedures` — done. Stacked on 4.4's branch only because both change the generated tables of Phase 4; the task needs nothing of it.
- **What was built:** `start-task`, `end-session` and `finish-phase` are `invocation: auto`, so their skills carry no `disable-model-invocation: true`; the rule is in the format (design §8.1, and the header of `tools/lib/procedures.mjs`): `auto` is the default, `explicit` only for a procedure that an agent must not start on its own judgment. The skills of this repository are regenerated. A test over the real procedures pins which are auto and which explicit, and that the Claude Code packaging adds `disable-model-invocation` to exactly the explicit ones.
- **Decisions / deviations from the plan:** (1) `triage-reports` (task 3.16) is also `auto`: the Git rules make the agent triage the open reports before other work, unasked, which is exactly the case the rule names. (2) `report-upstream` stays `explicit` (it acts outside the repository, and the owner's switch decides whether it asks or posts), and so do the new `update-framework` (a person asks for a version) and the four named in the task. (3) 4.5 measures the block with these values; the block lists every procedure whatever its invocation, so its rows do not change.
- **Verified by:** `tools/lib/skills.test.mjs` (the invocations of the real procedures and the packaging of each), the regenerated skills (the `.claude/skills` of the four have no `disable-model-invocation`), `harness check all`, `npm test`, lint, typecheck. The probe is the harness review's, and a signed-in session can run it with `claude -p "continue Phase 1"` in a project bootstrapped from this tree.
