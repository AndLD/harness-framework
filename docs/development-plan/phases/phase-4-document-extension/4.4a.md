# 4.4a — The agent cannot load most procedures as skills

**Status:** ✅ · **Agent:** C2 · **Size:** 2 SP

**The agent cannot load most procedures as skills**: seven of the eight procedures are `invocation: explicit` (all but `open-pull-request`), and the Claude Code preset writes them with `disable-model-invocation: true`, so only a person typing `/<name>` loads them. Their descriptions are written as triggers ("Use when …") that never fire, and the agent reaches them only through the table of the always-loaded entry file. That includes `start-task`, `end-session` and `finish-phase`, which the method requires of every agent unasked (finding H-20261103-03 of AndLD/bot-rts). Make those three `auto`, keep `explicit` for the ones a person starts (`release`, `code-review`, `harness-review`, `new-adapter`), and write the rule in the procedure format: `explicit` only for a procedure that an agent must not start on its own judgment. 4.5 then measures the block with these values. Verified by the skills generator's tests (the three have no `disable-model-invocation`), by the regenerated skills, and by a probe on a scratch project in which "continue Phase 1" loads `start-task` as a skill.
