# I-42 — The branch update by the workflow leaves a pull request with no checks

**Status:** ⬜ · **Agent:** C2 · **Size:** 2 SP · **Area:** host adapters · **Reported:** —

Found at step 5 of flow 4 (#236): after a merge into `develop`, `update-branches.yml` merges `develop` into the open branches as a bot; the bot's `pull_request` run waits in `action_required`, so the pull request has no checks and the host refuses its merge. The flow pushed an empty commit with the owner's credential to start the checks (as on #223). The workflow comes from `adapters/host/github/templates/update-branches.yml`.

**Done when:** a branch that the workflow updates gets its required checks without a person's push, or the adapter says how a project allows them, and a test of the template holds it.

**Verify with:** `node --test`, `node tools/harness.mjs check all`, and a pull request updated by the workflow on this repository.
