# I-48 — `harness host protect` sets required checks with no expected source

**Status:** ⬜ · **Agent:** C2 · **Size:** 1 SP · **Area:** host adapters · **Reported:** the [first security review](../../quality-reviews/security/2026-11-08.md), finding S-20261108-05

The ruleset that `harness host protect` writes gives each required check a context name only, so anyone with write access can satisfy a required check without the workflow having run.

**Done when:** `harness host protect` sets the expected source of each required check, the probe S3-009 finds nothing on a repository it has set, and a test holds it.

**Verify with:** `node --test` and `node tools/harness.mjs check all`.
