### 2026-11-05 — the account in the log, the account check of the reuse rule, and the fallback to a fresh worker
- **Branch:** `bugfix/I-10-worker-account-fallback` — done; pull request #93, which waits for the owner's approval of the contract addition (auto-merge off).
- **What was built:** (1) The flow-log template's executor line gains `**Account:**`; `workerEntries` and `previousWorker` read it (a log without it reads as before, the
  account null). (2) The runtime contract (still version 2: the addition is optional, so no adapter fails) gains the optional operation `account()` of an executor, means to
  read the account the orchestrator runs on; the Claude Code session reads it by `printenv CLAUDE_CODE_USER_EMAIL` (the desktop app) or `claude auth status` (the command line,
  whose folder decides the account); the manual executor returns none, the subagent has none (it is never reused). The conformance suite holds an `account` that is given to
  be an operation returning a list of means. (3) `harness flow dispatch --account <id>`; `decideReuse` adds "another account" when both accounts are known and differ, "the same
  account" when they match, and nothing when one is unknown. (4) Beside every continue, `dispatch` prints the fresh start to fall back on, with its log line; `run-flow` says to
  take it when the continue fails for any reason, never to retry, and to log a D0 decision. Docs: the contract, the plan method §10, the design §12, the README, the changelog.
- **Decisions / deviations from the plan:** an unknown account (not passed, or a log written before the field) does not forbid the reuse: the fallback covers a continue that
  fails, so the orchestrator is not made to read the account before every step. The fallback starts the step on its own model, not a model kept to stay warm.
- **Problems / blockers / findings:** none. Found on 2026-11-05: `claude -p --resume <worker>` from another account's folder answers "No conversation found with session ID"
  at once, before any model call, so a failed continue costs nothing.
