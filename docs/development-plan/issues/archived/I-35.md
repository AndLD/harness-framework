# I-35 — `package-lock.json` names the version `0.1.0`

**Status:** ✅ · **Agent:** C1 · **Size:** 1 SP · **Area:** checks · **Reported:** —

**`package-lock.json` names the version `0.1.0`**: `harness release` sets the version in `package.json` and `framework.json` but not in `package-lock.json`, whose `version` (and that of its root package) still reads `0.1.0` at `0.5.0`. Found by the worker of the cut of `0.5.0` (flow 3, step 9f). A fix: the release sets the version of the lock file too when the project has one (both fields), the lock of this repository is brought to the current version, and the check of the versions compares it; verified by a test of `harness release` on a tree with a lock file.
