# I-22 — A bootstrap does not create the folder of the off-plan record

**Status:** ✅ · **Agent:** C1 · **Size:** 1 SP · **Area:** bootstrap and sync · **Reported:** —

**A bootstrap does not create the folder of the off-plan record**: task 2.5 (#159) added the optional profile role `paths.offPlan` and its folder with a `README.md` that gives the format of a record, but `harness init` and `bootstrap` neither set the role nor write the folder, so a new project has the rule "nothing merges without a record" in its method and no place for the records until someone adds both by hand. The owner decided (2026-11-07) that a bootstrap creates the folder. The fix: a scaffold template for the folder's `README.md` (in `core/templates/scaffold/`, listed in `scaffold.json`), and a default of `paths.offPlan` for a new project in the starter answers, so that `check off-plan` runs from the start; an adopted project keeps its settings, and the changelog says how an existing project turns it on. Found by the worker of step 4 of flow 2.
