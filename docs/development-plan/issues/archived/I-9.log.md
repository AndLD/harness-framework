### 2026-11-04 — the renderer renders a condition inside a line, and refuses any other block tag there
- **Branch:** `bugfix/I-9-inline-conditions` — done.
- **What was built:** `tools/lib/render.mjs` resolves `{{#if role}}…{{/if}}` and `{{#unless role}}…{{/unless}}` closed on the same line (innermost first, so they nest) before it fills the placeholders: the text between the tags is kept or left out, the rest of the line stays, and a line that held only a condition left out is left out. A block tag still inside a line after that (unclosed, mismatched, an `each`) is an error naming the tag. `requiredPaths` (the placeholders outside every block and every condition inside a line) replaces `neededRoles` of `procedures.mjs`, so a role inside such a condition is optional; `placeholderPaths` also lists the paths of conditions inside a line. The four skills that carried the raw tags (`change-plan`, `end-session`, `triage-reports`, `run-flow`) are regenerated.
- **Decisions / deviations from the plan:** (1) The renderer renders the inline conditions rather than refusing them: they read naturally in prose, and the procedures in `core/` keep them unchanged, so the fix does not touch `run-flow.md`, which the open pull request of task 5.3 rewrites. (2) The refusal is in the renderer, not in a separate check of the generated files: every generated file goes through it, so no leftover tag can reach one. (3) Only `{{#…}}` and `{{/…}}` tags are refused, not every `{{`: a value of a profile may hold braces of another tool's templates.
- **Verified by:** `render.test.mjs` (conditions inside a line kept, left out, nested, a line left empty dropped; unclosed, mismatched and `each` tags refused; `requiredPaths`), `procedures.test.mjs` (a role inside an inline condition is optional; every procedure of the framework renders with no `{{` for this repository's profile and for it without `documents.planMethod`, `paths.backlog` and `host.autoMerge`); `npm run harness -- sync --local` leaves no `{{` in `.claude/skills/*/SKILL.md`; `npm test`, lint, typecheck, `docs:check`.
- **Next step:** none; projects take the fix with the next version.
