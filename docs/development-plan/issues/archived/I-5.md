# I-5 — A probe table of the older shape fails `check probes` without saying which columns it expects, and the note does not list the action

**Status:** ✅ · **Agent:** C1 · **Size:** 2 SP · **Area:** checks · **Reported:** [issue 64](https://github.com/AndLD/harness-framework/issues/64) · **Log:** [I-5.log.md](./I-5.log.md)

**A probe table of the older shape fails `check probes` without saying which columns it expects, and the note does not list the action**: the table of the harness-review bindings of a project had the columns `Id | Scenario | Expected`; the parser reads the third cell as the areas, so `check all` printed 37 lines such as `the probe P5 names the area "Names the CORE files", which is not an area`. The note of the version lists the new columns only under "What changed" and offers the probes P5 and P6 as optional. A required action makes the table `Probe | Scenario | Areas | Words read at the last review`, with `check probes` as its check, and `check probes` says the columns it expects when a table has others. Verified by a test of a bindings file with the older table. Reported by AndLD/bot-rts: [issue 64](https://github.com/AndLD/harness-framework/issues/64).
