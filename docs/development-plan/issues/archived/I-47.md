# I-47 — `check security` reports S2-001 on each workspace that the root lock file covers

**Status:** ✅ · **Agent:** C2 · **Size:** 1 SP · **Area:** checks · **Reported:** —

Found by the take of `0.6.0-dev.1` (AndLD/bot-rts#306): `checkManifests` in `tools/lib/security-deps.mjs` looks for a lock file only beside each manifest, so every workspace `package.json` of an npm workspaces project gets the finding "no lock file is tracked beside it", although the lock at the root pins it. A project that turns `checks.security` on then fails on findings that are not true.

**Done when:** a workspace manifest covered by a lock file at the root of its workspaces is not reported by S2-001, a manifest with no lock at all still is, and tests hold both.

**Verify with:** `node --test` and `node tools/harness.mjs check all`.
