# I-23 — The take of a version names no services that the project's gate needs

**Status:** ⬜ · **Agent:** C1 · **Size:** 1 SP · **Area:** procedures · **Reported:** —

**The take of a version names no services that the project's gate needs**: the procedure `update-framework` runs the project's checks and its gate, but says nothing of the services the gate depends on (a database, a container runtime), so a fresh worker that takes a version meets a failure such as "Can't reach database server" before it reaches the real result. Found by the worker of step 7b of flow 2 (the take of `0.4.0-dev.1` in AndLD/bot-rts, whose API tests need Docker and PostgreSQL). A fix: the procedure's verify step tells the agent to start the services that the project's test commands need (the project's profile or stack file names them), and to say in its report which it started; verified by the procedure's text and its rendered skill.
