# I-40 — The template repository does not ask for the flows' permissions

**Status:** ⬜ · **Agent:** C2 · **Size:** 1 SP · **Area:** bootstrap and sync · **Reported:** —

Found by the worker of I-30 (step 6a of flow 4): `harness init` now asks for the default permission mode of a flow's workers and the tools they may use, but `harness template` leaves the two `flows.permissions` questions out, so a project made from the template repository is not asked; it sets them with `--set flows.permissions.mode=<mode>`. Making the template ask needs its tree to match the run with flags only.

**Done when:** a project made by `harness template` is asked the two questions, or the template's guide says how to set them, and a test holds it.

**Verify with:** `node --test` and `node tools/harness.mjs check all`.
