# I-30 — The bootstrap does not ask for the flows' default permissions

**Status:** ⬜ · **Agent:** C2 · **Size:** 2 SP · **Area:** bootstrap and sync · **Reported:** —

**The bootstrap does not ask for the flows' default permissions**: I-27 gave the profile the role `flows.permissions` (a project's default for the workers of its flows), but `harness init` does not ask for it, so a new project learns of it only from the profile's roles. The worker of I-27 tried an adapter `firstSteps` entry, which added a step to every bootstrap of the runtime and a "Done once" block to every stack file and broke two tests, so it was dropped. A fix: a question of `init`, shown only when the runtime adapter declares the modes it offers, whose answer writes the role; verified by tests of an `init` with and without the answer. Split from I-27 on 2026-11-07 by the orchestrator of flow 3.
