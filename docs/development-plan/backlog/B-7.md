# B-7 — A gate on the host for the release path

**Status:** Proposed · **Size:** 3 SP · **Area:** host adapters · **Source:** agent

The [first security review](../../quality-reviews/security/2026-11-08.md) (finding S-20261108-07, medium) found that the release path has no gate on the host: no ruleset targets tags, immutable releases are off and the release job has no environment, so a pushed or moved tag becomes a release. What is wanted: a tag ruleset that limits creating and updating tags, immutable releases, and an environment on the release job.

Filed on 2026-11-08 when Phase 2 was closed, on the owner's word that every finding has a place. It waits for the owner to promote it.
