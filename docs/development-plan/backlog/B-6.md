# B-6 — A sandbox for agent sessions, with a list of hosts, in the runtime preset

**Status:** Proposed · **Size:** 3 SP · **Area:** runtime adapters · **Source:** agent

The [first security review](../../quality-reviews/security/2026-11-08.md) (finding S-20261108-04, high) found that a session of the agent runtime combines private data, outside text and a way out, with no sandbox. What is wanted: the runtime's sandbox with a list of allowed hosts in the preset, and the triage of outsiders' reports in a session without write tools. The details stay out of this file while the finding is open (section 7 of the security method).

Filed on 2026-11-08 when Phase 2 was closed, on the owner's word that every finding has a place. It waits for the owner to promote it.
