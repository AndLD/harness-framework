# B-9 — Automated dependency and configuration audits

**Status:** Proposed · **Size:** 2 SP · **Area:** stack adapters · **Source:** agent

The [first security review](../../quality-reviews/security/2026-11-08.md) (finding S-20261108-11, low) found that dependency and configuration audits are not automated, so a known vulnerability or a change of the registry is noticed by chance. What is wanted: an update tool for the ecosystems, the actions included, and a scheduled job that runs `harness check security --audit`.

Filed on 2026-11-08 when Phase 2 was closed, on the owner's word that every finding has a place. It waits for the owner to promote it.
